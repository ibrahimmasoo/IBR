الداشبورد مش هتشتغل إضافة / تعديل / حذف إلا بعد 3 خطوات:

1) افتح Supabase > SQL Editor
وشغّل الملف:
sql/supabase_schema.sql

2) افتح Supabase > Authentication > Users
واعمل مستخدم جديد بإيميل وباسورد

3) افتح admin.html
وسجّل دخول بنفس الإيميل والباسورد

بعدها هيشتغل:
- إضافة مشروع
- تعديل مشروع
- حذف مشروع
- إضافة صورة
- رفع صورة على Storage
- إضافة لينكات
- تعديل النصوص
- إظهار الإحصائيات

مهم:
لو الصفحة فتحت لكن الأزرار مش شغالة، فده غالبًا لأنك لسه ما عملتش Login أو ما شغلتش ملف SQL.
