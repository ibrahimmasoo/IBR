الخطوات:
1) ارفع الملفات كلها إلى GitHub بدل الملفات القديمة.
2) في Supabase افتح SQL Editor وشغّل الملف: sql/supabase_schema.sql
3) افتح admin.html
4) من الداشبورد تقدر تعدل النصوص والمشاريع والصور واللينكات.
5) الموقع العام index.html و projects.html و gallery.html بقوا يقرأوا من Supabase مباشرة.

مهم:
- الداشبورد حالياً بدون تسجيل دخول، يعني أي حد يفتح admin.html يقدر يعدل.
