# لوحة تحكم كاملة لموقعك مع Supabase

الملف ده فيه موقعك بعد تطويره بحيث يبقى مربوط بـ Supabase وفيه:

- `admin.html` لوحة تحكم كاملة
- `main.js` تحميل المحتوى ديناميكيًا من قاعدة البيانات
- `admin.js` إدارة النصوص والمشاريع والصور واللينكات والإحصائيات
- `sql/supabase_schema.sql` كود SQL الكامل لتجهيز الجداول والسياسات والإحصائيات والـ storage
- `supabase-config.js` إعدادات الاتصال

## الخطوات

### 1) جهز قاعدة البيانات
افتح Supabase → SQL Editor → New query
ثم انسخ محتوى الملف:

`sql/supabase_schema.sql`

وشغله بالكامل مرة واحدة.

### 2) أنشئ مستخدم أدمن
من Supabase → Authentication → Users
اعمل مستخدم جديد بالإيميل والباسورد.

بعدها افتح:

`admin.html`

وسجل دخول بنفس الإيميل والباسورد.

### 3) ارفع الموقع على GitHub Pages
ارفع كل الملفات كما هي إلى المستودع.

### 4) إدارة الصور
تقدر تضيف صورة بطريقتين:

- تحط رابط صورة مباشر
- أو ترفع صورة من جهازك داخل `site-media` bucket في Supabase Storage

### 5) الإحصائيات
الموقع بيسجل تلقائيًا:

- عدد الزيارات
- الزوار المميزين
- الصفحات الأكثر زيارة
- آخر الزيارات

## ملاحظات مهمة

- **ما حطّتش كلمة مرور قاعدة البيانات** لأن السطر اللي بعته فيه `[YOUR-PASSWORD]` فقط، وده طبيعي.
- الموقع الأمامي يستخدم `Project URL` و `Publishable Key` فقط.
- لوحة التحكم تعتمد على `Supabase Auth`، وده أفضل من وضع كلمة مرور ثابتة في الكود.
- لو عايز لاحقًا أضيف لك:
  - رفع CV
  - إدارة رسائل الفورم
  - Newsletter
  - Blog system
  - SEO panel
  - تعدد لغات من الداشبورد
  يبقى سهل نكمل فوق نفس البنية.
